# NiceNIC WHMCS Domain Registrar Module

**Official ICANN Registrar Module for WHMCS with 0% Fee Crypto Billing**

Connect your WHMCS installation to NiceNIC for domain registration, renewal, transfers and supported domain management.

Provided by NiceNIC, an ICANN-accredited registrar. ICANN accreditation applies to the registrar; it does not imply certification of this software by ICANN.

**Crypto billing:** Fund your NiceNIC account with supported cryptocurrencies, then use the available balance for eligible domain orders. NiceNIC adds a 0% processing fee. The online payment provider currently charges a 1.5% service fee, and wallet or network fees may apply. Check the [payment options](https://nicenic.com/payment-options.php) before paying.

Customer payment collection in your WHMCS store requires a separately configured payment gateway.
